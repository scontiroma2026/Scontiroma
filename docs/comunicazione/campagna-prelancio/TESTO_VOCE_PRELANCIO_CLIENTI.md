## Versione corta (circa 12–15 secondi, senza la frase sul 18+)
> Stai cercando sconti vicino a te? Sta arrivando Sconti Roma: le offerte dei negozi di Roma e dintorni, in un'app. Scrivici AVVISA e ti avvisiamo noi appena si parte. Gratuita nella fase di lancio. Sconti Roma, stiamo arrivando.

**Scritte a schermo (sempre, anche nella corta):** «18+ · Roma e dintorni», «Gratuita nella fase di lancio», «Scrivi AVVISA · link in bio», lontane dal bordo basso. Il «18+» resta quindi sullo schermo nella versione corta.

## Controllo regole (14/10)
| Regola | Esito |
|---|---|
| Niente data di lancio | Sì: «sta arrivando», «appena si parte», «stiamo arrivando»; nessun giorno, mese o «tra X giorni» |
| Lista d'attesa con AVVISA | Sì: «scrivici AVVISA»; l'email non si chiede mai in chat (risposta con il link: `CALENDARIO_PRONTO.md` §6) |
| Quartieri / zone pilota | Sì: nessuno; solo «Roma e dintorni» |
| Marchi di terzi | Sì: nessuno |
| %/€, prezzi, «gratis per sempre», «nessuna commissione» | Sì: nessuno; sul costo solo «gratuita nella fase di lancio» |
| 18+ | Sì: parlato nella completa, scritta a schermo in entrambe |
| Tono neutro, nessuna scarsità inventata | Sì |
| Promesse | Sì: «Stai cercando sconti vicino a te?» è una domanda; non promette sconti specifici né quantità. «L'app che raccoglie le offerte dei negozi» è vero solo se al momento della pubblicazione almeno un negozio ha un'offerta pronta (come la frase «stiamo mettendo insieme le offerte»): **controllare quel giorno** |
| Veri | Sì: voce di una persona vera, nessuna testimonianza |
| Consenso | Sì: AVVISA porta al modulo con consenso e conferma via email; modo per dire no nella risposta (STOP) |
